Vermeil 1.0.0 is the first release: an editorial theme for jewelry and fine accessories, with full-bleed imagery, display typography and a drawer-first shopping experience.

### Added

- Important: A complete set of pages: home, product, collection, search, cart, blog, blog post, contact, page not found, password and gift card.
- A product page you build from blocks, with a full-screen gallery, video, 3D models, color and image swatches, pickup availability, Shop Pay Installments and complementary products.
- Filtering and sorting on collection and search pages, in a drawer that updates results without reloading the page.
- Predictive search, a cart drawer, a mega menu option and a sticky header.
- 17 sections for the home page and other pages, including a hero, slideshow, editorial split, featured product, testimonials, video and contact form.
- Four color schemes, fonts from the Shopify font library, and settings for page width, spacing, buttons and product cards.
- Blog posts with tags, comments and links to the previous and next post.
- A gift card page with a copy button, QR code, Apple Wallet and printing.
- Support for right-to-left languages, keyboard navigation and screen readers.
