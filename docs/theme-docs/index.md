# Vermeil documentation

Vermeil is a Shopify theme for jewelry and fine accessories. It pairs full-bleed imagery and large display
type with a drawer-first shopping experience: the menu, filters and cart all open as drawers, so customers
never lose their place.

These pages cover setting up your store for Vermeil, customizing every page, and getting help.

## Contents

- [Getting started](getting-started.md): install the theme and prepare your store
- [Pages](pages.md): what each page template shows and how to customize it
- [Settings reference](settings-reference.md): every theme setting, section and block, with defaults
- [FAQ](faq.md): answers to common questions
